# Function-use-at-first-time-
comparere - README

Description🖥️
This project compares two numbers and tells which one is bigger or if both are equal.

Features✨✨
- Compares two numbers
- Tells bigger number
- Handles equal case

Parameters
- *a*: First number
- *b*: Second number

Return Value
- String message like "X is bigger than Y"
- Returns "equal" if both numbers are same

How it Works👷👷
1. Checks if a is greater than b
2. Checks if b is greater than a  
3. If none, both are equal
